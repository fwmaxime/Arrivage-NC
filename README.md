# ARRIVAGE NC — prototype

Prototype interactif d'ARRIVAGE (Nouvelle-Calédonie). Toutes les données sont fictives et le paiement est simulé.

- `index.html` : le prototype complet en une seule page, servi par GitHub Pages.
- `sources/` : le code source (React + TypeScript, assemblé avec esbuild via `build.sh`).
